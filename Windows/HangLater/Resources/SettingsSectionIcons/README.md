# Settings section icon mapping

Original PNGs supplied in `settings-section-icons-light-dark.zip`; copied without recoloring, cropping, or recompression.

| Setting | Asset in each theme folder | Display size |
| --- | --- | --- |
| Desktop clothesline / 桌面晾衣绳 | `desktop-clothesline.png` | 22 × 16 DIP in a 22 × 22 slot |
| Workday hours / 工作日时间 | `workday-hours.png` | 18 × 18 DIP |
| Task types / 任务类型 | `task-types.png` | 20 × 19 DIP |
| Current workday summary | `workday-hours.png` | 21 × 21 DIP |

Use `light/` when `LightAppearance` is true; `dark/` otherwise. Selection changes label weight, ink, and sidebar background, not the PNG. Originals are 2× density. All six files are embedded WPF resources.
